# Clayspad — what each surface says

One page, so that no two surfaces say the same thing.

The problem this file exists to prevent: every line in the kit is *true*, so it
is easy to reach for the best one every time — and then the banner, the bio and
the post all open with "the kiln has no door", which reads as a template rather
than a voice. Somebody who sees three of these in a row should learn three
things, not the same thing three times.

**Everything here is English**, as a standing rule across the account.
**Nothing here states a figure** — those are in the contracts.

## The map

| Surface | Angle | The line |
| --- | --- | --- |
| **Header banner** | What it *is*, permanently. Not tied to any launch. | `Fired once, and for good.` |
| **Bio** | What you do here and what you get. Functional, no metaphor. | `Most of what you launch goes into a pool nobody can drain…` |
| **Launch post image** | This moment. Short enough to read at a glance. | `The fire is lit.` |
| **Launch post body** | The announcement, and the wallet it will come from. | Opens on the mechanism, not on a slogan. |
| **Pinned post** | The full explanation, for whoever taps through. | The mechanism in three short paragraphs. |
| **Site landing** | The long form, with the straight answers. | `The kiln has no door.` |

The kiln line is reserved for the site, where there is room to explain what it
means one line further down. On a banner or an image it is a slogan with nothing
behind it; on the landing page it is a claim the next paragraph backs up.

## Why these angles, in this order

Somebody meets the account in a predictable sequence: the banner and the avatar
first, then the bio, then whatever post brought them, then the site if they are
still curious. So the surfaces get progressively more specific:

1. **Banner** — an identity. It will sit there for months, so it must not
   mention a launch that will be old news in a week.
2. **Bio** — the functional answer to "what is this for", in plain words with no
   metaphor at all, because the metaphor is already above it on the banner.
3. **Post image** — the event. Three words, because it is competing with the
   picture it sits on.
4. **Post body** — the only surface with room for the deployer wallet, which is
   the one thing on the account somebody needs to be able to copy.
5. **Site** — everything else, including the disclosure the short surfaces
   cannot carry.

## The rule for anything new

Before adding a line anywhere, read this table. If the new line makes the same
point as one already in it, either cut the new one or move the old one — do not
run both. Two surfaces repeating a claim does not make it twice as convincing;
it makes the account look automated.
